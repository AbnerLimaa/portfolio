# Abner Lima - Portfolio

Personal portfolio and blog of Abner Lima, a Software Engineer specialized in high-performance distributed systems, event-driven architectures, and cloud infrastructure with experience working for the financial market.

## Tech Stack

This portfolio is built with modern, performant web technologies:

- **Framework:** [Astro](https://astro.build/) (Static Site Generation)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Content:** Astro Content Collections with Markdown (`.md`) and Zod schema validation
- **Routing:** File-based routing with Astro View Transitions for seamless navigation

## Repository Structure

The site's content is managed using Markdown files, making it incredibly easy to update projects, work experiences, and blog posts.

- `src/content/work/` — Professional experience (e.g., BTG Pactual, Mobills)
- `src/content/projects/` — Open-source and side projects (e.g., Cajá CLI)
- `src/content/blog/` — Blog posts and technical writing
- `src/pages/` — Core pages (`index.astro`, `about.astro`, etc.)
- `src/site.config.ts` — Global configuration (site name, tagline, social links)
